プライバシーポリシー

ラーメンマップ

本アプリ「ラーメンマップ」（以下「本アプリ」）は、ユーザーの個人情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 収集する情報

本アプリは、以下の情報を収集することがあります。 ・位置情報 　現在地周辺のラーメン店を検索するために使用します。位置情報はお客様の明示的な許可のもとでのみ取得します。取得した位置情報は、周辺の店舗を検索する目的で当方のサーバーおよびGoogle Places APIへ送信されます。位置情報を広告目的で利用したり、第三者へ販売・提供したりすることはありません。 ・利用情報 　アプリの利用状況（画面閲覧、機能の使用、検索キーワードなど）を収集し、サービスの改善に役立てます。収集はFirebase Analyticsを通じて行われます。 ・広告識別子 　広告配信のために、広告識別子（iOSのIDFA、AndroidのAAID）などが使用されることがあります（第6条をご参照ください）。

2. 情報の利用目的

収集した情報は、以下の目的で使用します。 ・近隣のラーメン店の検索・表示 ・アプリの機能改善・不具合対応 ・利用傾向の分析によるサービス向上 ・広告の配信

3. 第三者サービスの利用

本アプリは以下の第三者サービスを使用しており、各サービスのプライバシーポリシーが適用されます。 ・Google Maps Platform（地図表示・店舗検索） 　周辺のラーメン店の検索・表示に使用します。現在地や検索内容は当方のサーバーを経由してGoogle Places APIに送信されます。取得した店舗データは、表示の高速化とAPI呼び出し回数の削減のため、端末内および当方のサーバーで一定期間キャッシュされます。 ・YouTube Data API v3（動画情報の取得） 　店舗に関連するレビュー動画の情報を取得するために使用します。APIの利用上限に達した場合はその旨を表示し、それ以外のエラー時は動画情報の表示を行いません。 ・Firebase / Google Analytics（利用状況の分析） 　アプリの利用状況を匿名で収集・分析します。 ・Google AdMob（広告配信） 　本アプリ内に広告を表示します（第6条をご参照ください）。 各サービスのプライバシーポリシーについては、Google のプライバシーポリシーをご参照ください。

4. 位置情報の取り扱い

位置情報は、現在地周辺のラーメン店を表示・検索する目的にのみ使用します。位置情報を第三者へ販売・提供することはありません。位置情報の利用を停止したい場合は、端末の設定からアプリへの位置情報アクセスを拒否してください。

5. 情報の保存について

食べた店・行きたい店・レビューなどのデータはお客様の端末内にのみ保存されます。これらのデータを外部サーバーへアップロードすることはありません。

6. 広告について

本アプリはGoogle AdMobによる広告を表示します。AdMobは、お客様の興味・関心に応じた広告を配信するために、広告識別子（iOSのIDFA、AndroidのAAID）などの情報を使用することがあります。 iOS端末では、アプリのトラッキングの透明性（App Tracking Transparency）に基づき、トラッキングの許可をお客様に確認します。許可しない場合でも本アプリはご利用いただけます（表示される広告がお客様の関心に基づかないものになる場合があります）。 Googleによる広告配信およびデータの取り扱いについては、こちらをご参照ください。

7. アプリ内課金について

本アプリには、広告を非表示にする有料機能（アプリ内課金）があります。決済は各アプリストア（App Store / Google Play）を通じて行われ、当方がお客様のクレジットカード番号などの決済情報にアクセスすることはありません。購入・返金の取り扱いは各ストアの規約に従います。

8. 子どものプライバシー

本アプリは13歳未満の方を対象としていません。13歳未満の方の個人情報を意図的に収集することはありません。

9. プライバシーポリシーの変更

本ポリシーは予告なく変更されることがあります。重要な変更がある場合はアプリ内でお知らせします。

10. お問い合わせ

プライバシーポリシーに関するご質問は、アプリ設定画面の「お問い合わせ」よりご連絡ください。
