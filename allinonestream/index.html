プライバシーポリシー

AllInOneStream

本アプリ「AllInOneStream」（以下「本アプリ」）は、ユーザーの個人情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 収集する情報

本アプリは、以下の情報を収集することがあります。 ・匿名ユーザーID 　アプリ起動時に Firebase Authentication により自動生成される匿名IDです。ユーザーの氏名・メールアドレス等の個人情報は一切収集しません。 ・登録配信者情報 　ユーザーが登録したYouTubeチャンネルおよびTwitchアカウントの情報を、端末内のローカルデータベースおよびFirestore（プッシュ通知の配信に必要な場合のみ）に保存します。 　また、Twitchアカウントでログインした場合、フォロー中のチャンネル一覧を取得し、ユーザーが選択した配信者を端末内のローカルデータベースに保存します。Twitchアカウントの認証情報（アクセストークン）はアプリ終了時に破棄され、サーバーには保存しません。 ・通知設定 　配信者ごとの通知ON/OFF設定を端末内およびFirestoreに保存します。 ・アプリ利用状況 　画面閲覧・コンテンツのタップ・配信者の追加・フィルター操作などの利用状況をFirebase Analyticsを通じて匿名で収集し、サービス改善に役立てます。 ・プッシュ通知トークン 　Firebase Cloud Messaging（FCM）によるプッシュ通知の配信のため、端末のFCMトークンをFirestoreに保存します。

2. 情報の利用目的

収集した情報は、以下の目的で使用します。 ・登録配信者のYouTube動画・Twitch配信情報の取得・表示 ・ライブ配信開始・新着動画のプッシュ通知の送信 ・アプリの機能改善・不具合対応 ・利用傾向の分析によるサービス向上

3. 第三者サービスの利用

本アプリは以下の第三者サービスを使用しており、各サービスのプライバシーポリシーが適用されます。 ・YouTube Data API v3（動画・チャンネル情報の取得） 　登録配信者の最新動画・ライブ配信情報を取得するために使用します。 　Google プライバシーポリシー ・Twitch API（配信情報の取得およびフォロー中チャンネルのインポート） 　登録配信者のライブ配信状況を取得するために使用します。また、ユーザーがTwitchアカウントでログインした場合、フォロー中のチャンネル一覧を取得するために使用します（任意・ログイン時のみ）。 　Twitch プライバシーポリシー ・Firebase Authentication（匿名認証） 　個人情報を収集せずにユーザーを識別するための匿名IDを生成します。 ・Firebase Firestore（通知設定の管理） 　プッシュ通知の配信に必要な設定情報を保存・管理します。 ・Firebase Analytics（利用状況の分析） 　アプリの利用状況を匿名で収集・分析します。 ・Firebase Cloud Messaging（プッシュ通知） 　ライブ配信開始・新着動画のプッシュ通知を配信します。 ・Google AdMob（広告配信） 　アプリ内に広告を表示します。AdMobは広告識別子を使用することがあります。 　Google プライバシーポリシー

4. 端末内に保存されるデータ

以下のデータはお客様の端末内にのみ保存され、外部サーバーへ送信されることはありません。 ・コンテンツの既読履歴 ・コンテンツのタップ回数（広告表示頻度の管理用）

5. 広告について

本アプリはGoogle AdMobによる広告を表示します。AdMobはお客様の興味・関心に基づく広告を表示するため、広告識別子（IDFA / AAID）を使用することがあります。パーソナライズ広告の設定は端末の設定画面から変更できます。

6. 情報の第三者提供

本アプリは、以下の場合を除きユーザーの情報を第三者に提供しません。 ・ユーザーの同意がある場合 ・法令に基づく場合 ・上記「3. 第三者サービスの利用」に記載のサービスへの情報提供（各サービスの利用規約に基づく）

7. 子どものプライバシー

本アプリは13歳未満の方を対象としていません。13歳未満の方の個人情報を意図的に収集することはありません。

8. プライバシーポリシーの変更

本ポリシーは予告なく変更されることがあります。重要な変更がある場合はアプリ内でお知らせします。最新のポリシーは常に本ページに掲載されます。

9. お問い合わせ

プライバシーポリシーに関するご質問は、アプリ設定画面の「お問い合わせ」よりご連絡ください。
